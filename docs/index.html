Install

Pick how you use Claude.

Most people use the Claude app or claude.ai. If you code in Claude Code, use the second tab.

1Download, then open Customize

Get the file with the button above. In Claude, click Customize in the left sidebar.

2Plugins → + Add → Upload plugin

Three clicks at the top of the Customize page.

3Drop in the file, press Upload

You'll see “Content team is installed and ready to use.”

4Type /content-team + your topic

Open a new chat, pick it from the / menu, add your idea and send.

# inside Claude Code
/plugin marketplace add clevernat/content-team
/plugin install content-team@aiwalkthru
Then run it

Use /content-team followed by your topic. Each role is also its own skill, so /script-writer or /seo-specialist work on their own.

Source: plain Markdown skills in /skills. Fork it and make it yours.

FAQ

Good questions.

Does it work on the free Claude plan?

No. Claude plugins need a paid plan: Pro, Max, Team or Enterprise.

Is it safe?

It only adds instructions for Claude. There are no connectors, no code that runs, and nothing new is sent anywhere. Every file is readable on GitHub.

Can I change it?

Yes. It's MIT licensed. Download the source, edit the skills, and upload your own version.

How do I remove it?

Customize → Plugins → Yours → Content team → ⋮ → Remove.
