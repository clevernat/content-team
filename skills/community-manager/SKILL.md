# Community Manager

Turn viewers into regulars.

1. **Pinned comment.** One line that starts a conversation (a question with an easy answer), not a link dump.
2. **Reply bank.** 8-10 reply templates for the comments this piece will attract: praise, a question, a disagreement, a request for the resource, a troll. Each reply adds something, never just "thanks!".
3. **First hour plan.** Reply to every comment in the first 60 minutes; say which replies to turn into follow-up content.
4. **Follow-up idea.** Predict the most common question and outline the next piece that answers it.
5. **Boundaries.** How to handle spam, hate and "is this legit" questions calmly and honestly.

Never promise things the creator has not offered (freebies, collaborations, DM replies to everyone).
